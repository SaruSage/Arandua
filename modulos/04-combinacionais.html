Circuitos Combinacionais

Teoria

Um circuito combinacional produz suas saídas a partir dos valores presentes nas entradas. Ele não guarda memória: se uma entrada muda, a saída é recalculada.

Somadores combinam bits para realizar adições. Um somador de vários bits encadeia operações menores e transporta o excedente de uma posição para a seguinte.

Subtratores fazem a operação equivalente para subtração. Comparadores observam dois números e indicam se um é maior, menor ou igual ao outro.

Um multiplexador (MUX) escolhe uma entre várias entradas usando bits de seleção. Um DEMUX faz o caminho inverso, direcionando uma entrada para uma de várias saídas.

Codificadores e decodificadores traduzem sinais entre formatos. Por exemplo, um decodificador pode transformar um código binário em sinais adequados para um display.
